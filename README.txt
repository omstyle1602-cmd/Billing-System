OM STYLE DELHI - Billing & Stock System

GITHUB PE LIVE KARNE KE STEPS
1. github.com pe login karo -> New repository -> naam: omstyle-billing -> Public -> Create.
2. "uploading an existing file" pe click karo.
3. Zip extract karke ANDAR ki cheezein (index.html, css folder, js folder) drag-drop karo
   (zip ya OmStyle-Billing folder ko nahi, uske andar ki files/folders ko).
4. Commit changes dabao.
5. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
6. 1-2 minute baad link milega: https://<username>.github.io/omstyle-billing/

AUTO-SAVE FOLDER (har bill ka PDF aaj ki date wale folder me)
- Computer pe Chrome ya Edge me site kholo -> Settings -> Choose folder.
- Koi bhi folder chuno (jaise Documents/OmStyleBills) -> "Allow / Edit files" pe Allow.
- Ab har bill pe us folder me 2026-10-11 jaisa date folder khud banega, usme PDF save hogi,
  aur OmStyle_Data.xlsx update hoga.
- Site dobara kholne par pehle bill pe browser permission dobara pooch sakta hai - Allow kar do.
- Mobile/Safari/Firefox me folder save nahi hota; wahan PDF download hoti hai.

OUT-OF-STOCK MAIL
- Settings me email daalo -> Save -> Send test mail -> mail me FormSubmit ka Activate link click karo.

DHYAN DO
- Data browser (localStorage) me auto-save hota hai. Browser data clear karoge to ja sakta hai.
  Isliye History tab se Excel export kabhi kabhi le lo, ya auto-save folder use karo.
- Bill banane wala computer/browser hamesha same rakho.
